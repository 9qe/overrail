# How this project makes money

agentrouter is MIT and the core stays free forever. Money follows three rails, switched on in order. Nothing here is live yet — this page is the plan, published up front.

## Rail 1 — GitHub Sponsors (day one)

Live from day one: https://github.com/sponsors/9qe. Sponsorship covers the fixed costs of running an open-source project: CI and domains. No features are gated behind it.

## Rail 2 — Pro desktop build (after ~1,000 stars)

Once the project has roughly 1,000 stars and a real user base to validate demand, a paid desktop tier ships: agentrouter Pro.

What Pro adds:

- The Windows tray app — profile and failover status without touching the terminal
- Cost estimates, backed by an editable price table
- Smart task-based model routing

The open-core split, stated plainly:

- The OSS core — the CLI, the gateway, failover chains, the usage log — stays MIT forever.
- Bug fixes are never paywalled. If the free CLI breaks, the fix lands in the free CLI.
- Pro is convenience UI and analytics on top. If you never pay, nothing in the terminal gets worse.

The price is not set yet. It gets decided against real usage data when the tier ships, not guessed here.

## Rail 3 — hosted relay (long-term, speculative)

The distant option: a hosted relay with per-token billing, where the free OSS client is the funnel. This is the OpenRouter model — the client stays free, the hosted service bills per token.

The line that does not move: the free tool's keys stay local forever. The relay only ever handles keys the user explicitly uploads.

## Before any of this

Every price and deadline above is a proposal, not a promise. Validate against real usage data before building anything — if the data says otherwise, the plan changes.
